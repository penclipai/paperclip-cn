# Paperclip v2026.1026.0

> Released: 2026-10-26

Paperclip CN 本次更新完善桌面后台工作、任务工作区恢复和服务连接。

## 升级注意事项

- **升级会执行数据库迁移。** 相对 `v2026.1021.0`，本次包含 `0334`–`0377` 共 44 个迁移。升级前请备份数据库和实例数据；首次启动时等待迁移完成。回退需要恢复与旧版本匹配的备份。
- **新建 Claude/Codex 智能体的默认运行器按平台变化。** 在 Runner 可用且条件检查通过的 macOS（x64/arm64）及 Linux（x64/arm64、glibc ≥ 2.39）环境中，自动选择 Paperclip Runner。Windows、Linux musl 或未满足条件的环境继续使用 Legacy；Claude 在 macOS SSH 环境中也仍默认使用 Legacy。已有智能体不会被批量改写，显式运行器、模型和 provider 选择保持不变。

## 亮点

- **Windows 桌面应用可在后台继续工作。** 关闭主窗口后，应用可驻留在系统托盘；可从托盘或再次启动恢复窗口，并使用明确的「退出」操作正常停止。应用会保存可用的窗口位置、大小和最近的安全页面。
- **重要事件可显示私有原生通知。** 可为审批、运行失败和超时运行启用桌面通知。通知按当前公司访问权限筛选，并限制重复显示。
- **任务拥有更持久的工作区。** 任务可使用不绑定项目的持久工作区；恢复点和保留策略改善了闲置、关闭及嵌套工作区的恢复。恢复点过期时会提示，并在条件允许时重新创建工作区；实际可用性仍取决于仓库和执行环境。
- **服务连接选择更丰富。** 新增或完善 Google Workspace、1Password 服务账户、Supabase、Vercel、Unikraft Cloud、Braintrust 和 Ditto 等连接入口；各服务仍需按自身要求完成权限和连接配置。
- **可在引导中连接自定义 AI 网关。** 引导流程增加自定义 AI 网关连接选项，便于在受控环境中使用已有服务。

## 改进

- **产物增加实验性统一视图。** 在「设置 > 实验性功能」启用 Artifacts V1 后，可在产物页、任务侧栏和对话中以统一视图查看任务产物。
- **Cases 工作流可复用并保持状态。** 启用 Cases 后，可复用提示词工作流，并在持久工作流中保留同一任务内的智能体交接。
- **同类智能体的设置可批量调整。** 可一次更新兼容本地智能体的连接和默认模型，并预览将要应用的变更。
- **已有 Claude/Codex 智能体提供 Runner 升级入口。** 符合运行条件的智能体可在主动确认后升级；现有选择不会被静默替换。
- **任务与来源例程的关系更清晰。** 由例程创建的任务会保留其来源例程的链接。
- **公司可按需配置智能体观测。** 管理员可为受管理的 Claude/Codex 配置 Braintrust 或自定义 OTLP 目标，导出默认关闭。启用后，提示词、回复和工具内容的采集选项默认开启；配置时请确认接收方和采集范围。参见[观测配置说明](https://github.com/penclipai/paperclip-cn/blob/bcedd52818cc6257c72071b12fd2a0d0ed60488c/doc/agent-observability.md)。
- **连接设置增加基于模型的提示注入检查。** 需显式配置共享 OpenRouter 连接后启用；检查会发送脱敏工具结果给所选模型，调用费用计入 Costs，模型不可用时沿用内置检查。参见[配置与数据处理说明](https://github.com/penclipai/paperclip-cn/blob/bcedd52818cc6257c72071b12fd2a0d0ed60488c/doc/prompt-injection-prevention.md)。
- **审计页增加 Commentary 视图。** 可查看智能体提交的建议与反馈过程消息，按文本、智能体或类型筛选，并打开任务/运行上下文及分享消息链接。
- **GitHub 技能来源可选择跟踪分支。** 支持选择和校验授权分支或 revision，并在跟踪引用失效时修复来源。
- **新增实验性 Speko 浏览器语音接入。** 可从任务或智能体上下文发起浏览器通话；需要自有 Speko API key、agent ID 和公开 HTTPS 回调，费用由 Speko 单独计算。电话呼叫暂未作为已验证能力开放。
- **项目访问提示更可操作。** 当项目访问被拒绝时，界面会说明原因，并在授权条件满足时提供修复路径。
- **Grok 外部连接的支持得到加强。** 实验性 Grok Bot 智能体可通过外部连接配置；重新连接时可以复制配对码，并改善文件完成记录及失败后的继续处理。该能力仍要求已配置且可用的外部连接。
- **中文界面覆盖继续完善。** 项目访问、网关引导、错误提示和运行相关状态补齐中文文案；事件 ID、包名和 provider 标识等技术值保持原样。

## 修复

- **中文运行日志显示更完整。** 修复 UTF-8 字符跨输出分块或日志分页时可能出现的中文和表情乱码。([#178](https://github.com/penclipai/paperclip-cn/pull/178))
- **Windows OpenCode 安装错误更明确。** 识别未完成的 CLI 安装；本地 OpenCode 运行可显式配置标准错误的字符编码。
- **已有运行记录保留原样。** 升级后新产生的运行使用修复后的日志链路；此前已经保存的乱码不会自动改写。
- **桌面窗口恢复更安全。** 关闭、恢复、再次启动和正常退出使用受控的生命周期路径；无效窗口状态不会直接恢复。
- **工作区和运行清理更可靠。** 已结束运行、嵌套仓库和已失效恢复点的清理会保留恢复所需的状态，并避免阻塞后续重试。
- **运行器和连接故障信息更明确。** 改进了控制器重启期间的原生启动、远程产物、连接就绪和网关请求失败时的处理与诊断。
- **页面资源加载异常时可尝试一次重载恢复。** 改善了懒加载页面或样式加载失败后的体验。

## 升级指南

1. 升级前备份实例数据和数据库，并正常停止现有实例。
2. 首次启动新版本后等待 `0334`–`0377` 号数据库迁移完成。
3. 检查公司、智能体、任务、Connections 和模型设置，特别是自定义网关及外部 Grok 连接；新建智能体请确认默认运行器选择。
4. Windows 桌面用户可在设置中确认「关闭后驻留系统托盘」和原生通知偏好。选择「退出」会正常停止后台工作。
5. 如需启用智能体观测、模型检查或实验性语音，请先确认对应的连接、数据接收方和费用设置。
6. 如需回退，请恢复与旧版本匹配的数据库和实例数据备份；不要只替换应用文件。

## Windows 安装提示

本次 Windows 安装包未进行代码签名。Windows SmartScreen 或 UAC 可能显示「未知发布者」。请从本项目的 GitHub Release 下载，并使用同一发行页提供的 `SHA256SUMS.txt` 校验安装包。
