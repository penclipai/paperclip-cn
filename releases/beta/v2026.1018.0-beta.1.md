# Paperclip v2026.1021.0

Paperclip CN brings the upstream release scope to the fork with zh-CN-first
surfaces and Windows desktop support.

## 破坏性变更

- **升级会执行数据库迁移。** 相对 `v2026.716.0`，本版本包含 `0182`–`0333` 共 152 个迁移。升级前请备份实例数据和数据库；安装后首次启动时等待迁移完成，再恢复日常工作。
- **进行中的适配器登录需要重新开始。** `0224_unified_adapter_auth_sessions` 会清理升级时尚未完成的短期登录会话；不会批量删除已经保存的适配器凭据。`0225_drop_claude_setup_token_sessions` 移除了弃用的 Claude setup-token 会话表。
- **旧设置及其替代方式。** `brand_color` 不再生效，公司图标色由公司名称生成；上传上限由部署级 `PAPERCLIP_ATTACHMENT_MAX_BYTES` 控制，未设置时默认为 10 MB。`0236_remove_cheap_model_profiles` 会移除 `modelProfiles` 和任务 `modelProfile` 覆盖；请在现有连接和智能体设置中选择显式 provider/model。
- **自托管和 CLI 的 Node.js 要求提高。** 自托管和 CLI 环境需要 Node.js `>=24.11.0`；桌面版使用随安装包提供的运行时。
- **快捷键统一启用。** `0289_drop_user_keyboard_shortcuts` 移除的是个人启用/停用偏好；快捷键本身仍可使用。

## 亮点

- **任务产物可直接上传和查看。** 可在任务的 Artifacts 区域选择或拖放文件；CSV 提供表格预览，HTML 以隔离方式呈现，媒体文件支持图库式浏览。([upstream #15964](https://github.com/paperclipai/paperclip/pull/15964), [CN commit](https://github.com/penclipai/paperclip-cn/commit/762d680daf3563d42a0c4c280761c233b21713c7))
- **私有任务和项目的访问控制。** 可将任务或项目设为私有，并向指定参与者或私有项目成员授权；任务、运行和数据读取路径都会执行相应的访问检查。敏感工作仍应使用受信任的智能体和隔离环境。([upstream #10633](https://github.com/paperclipai/paperclip/pull/10633), [CN commits](https://github.com/penclipai/paperclip-cn/commit/cd86192ca2dd0c3dbd8c3382d0b1f5aa040b7e71), [d92ef1e](https://github.com/penclipai/paperclip-cn/commit/d92ef1e4b4841e12d613d2fba3a111eb33159b50), [c761282](https://github.com/penclipai/paperclip-cn/commit/c761282d760c4d6e263db90251a4e100ad3c0dc3))
- **智能体对话与任务衔接。** Agent Chat 支持持久对话；已完成的 handoff 可以回到对话中继续，任务会显示创建来源和后续关系。([CN commits](https://github.com/penclipai/paperclip-cn/commit/02380f23e9b40aac4cb74faf20f93687e26d49ce), [4ced6e22](https://github.com/penclipai/paperclip-cn/commit/4ced6e22cdd3d504ddbc6bfd83df1d4ce27646a3))
- **可选的 Grok Build Native ACP 运行器。** Paperclip Runner 可通过 ACPX 使用 Grok Build。运行环境仍需预置并验证 Grok Build 可执行文件及连接身份；该运行器默认不会自行启用。([upstream #13882](https://github.com/paperclipai/paperclip/pull/13882), [CN commit](https://github.com/penclipai/paperclip-cn/commit/f1a394bd30cb56fb9e479f98b9f50176fe921858))

## 改进

- **运行、恢复和人工交互更稳健。** 任务编辑、待输入状态、停止操作、状态说明和审批/答复排队得到改进；工作区恢复、空闲休眠与取消后的清理也得到加强。
- **连接和模型管理更集中。** Connections 支持更一致地管理运行时凭据、登录状态、自定义 provider、任务级路由以及订阅成本和 API 用量归因。
- **zh-CN 覆盖更完整。** 连接设置、外部适配器元数据、活动审计、智能体导航、任务属性、插件审计动作和响应式页签补齐中文文案。事件 ID、包名和 provider ID 等技术标识保留原样，便于排障。([CN #164](https://github.com/penclipai/paperclip-cn/pull/164))
- **Windows Desktop 退出和安装边界得到加固。** 嵌入式 PostgreSQL 的关闭顺序、子进程回收和缺失 `TEMP`/`TMP` 环境变量时的安装路径已得到针对性改进。([CN #164](https://github.com/penclipai/paperclip-cn/pull/164))

## Windows 下载提示

- **首发 Windows 安装包不带代码签名。** Windows 可能显示“未知发布者”或 SmartScreen 提示；企业设备上的策略也可能阻止安装。请仅从本项目的正式 GitHub Release 下载，不要绕过组织的安全策略。下载前后请按发布页提供的 SHA-256 校验值核对安装包。
- 如部署策略要求临时文件使用指定磁盘，请由管理员在提升权限的安装、卸载或运行进程中预先设置 `TEMP`/`TMP`；原生 UAC 提升可能重置该设置。

## 修复

- **诊断信息的脱敏更准确。** 单字符用户名、认证头和适配器密钥探测结果获得更严格的脱敏，同时保留排障所需的非敏感响应元数据。
- **任务恢复和错误反馈更可行动。** 改进了取消 Grok 启动、工作区复制回写、租约释放、provider deadline 和失败工作区任务的处理；错误会尽量保留可行动的上下文。
- **发布来源校验对齐 CN fork。** canary 来源校验、Cloud readiness 和 PR 质量检查使用 CN fork 身份，避免将上游仓库身份误作本 fork 的发布证据。

## 升级指南

1. 备份数据库和实例数据目录，并正常停止现有实例。
2. 自托管和 CLI 部署先确认 Node.js 版本为 `>=24.11.0`；桌面版使用捆绑运行时，无需单独安装 Node.js。
3. 安装新版本后先启动一次，等待迁移完成。
4. 检查公司、智能体、任务、Connections 和模型设置；升级时尚未完成的适配器登录请重新发起。
5. 如使用过 `brand_color`、`modelProfiles` 或任务 `modelProfile` 覆盖，请按上文替代方式重新配置。部署管理员应检查 `PAPERCLIP_ATTACHMENT_MAX_BYTES`，未设置时上传上限为 10 MB。
6. 迁移完成后，替换应用二进制文件或移动 npm 的 `latest` 标签都不能回退数据库结构；回退时请恢复与旧版本匹配的备份。
