# v2026.607.0

> Released: 2026-06-07

## Highlights

- **Paperclip CN localization repair** - Restores Chinese UI chrome after the upstream sync across issues, agents, sidebars, artifacts, project setup, routines, system notices, and onboarding, while keeping generated/user/agent content, raw logs, adapter IDs, model names, and paths untranslated. ([#139](https://github.com/penclipai/paperclip-cn/pull/139))
- **Artifacts are easier to scan** - Artifact views can now group work by task stacks, making related outputs easier to review together. ([#7654](https://github.com/paperclipai/paperclip/pull/7654))
- **Video artifacts get visual previews** - Video artifact cards now render thumbnails so users can recognize media outputs without opening each file. ([#7667](https://github.com/paperclipai/paperclip/pull/7667))
- **Project and agent surfaces refreshed** - Experimental information architecture updates improve the visual structure of project and agent areas. ([#7543](https://github.com/paperclipai/paperclip/pull/7543))

## Improvements

- **Issue interaction controls are more precise** - Interaction selectors were polished and checkbox confirmation interactions were added for clearer review flows. ([#7668](https://github.com/paperclipai/paperclip/pull/7668), [#7649](https://github.com/paperclipai/paperclip/pull/7649))
- **Task wording continues the Issue-to-Task transition** - User-facing copy keeps moving toward task-oriented language while preserving technical issue identifiers where they are part of the product contract. ([#7651](https://github.com/paperclipai/paperclip/pull/7651))
- **Login forms are friendlier to assistive tech and password managers** - Login accessibility and metadata were improved. ([#7660](https://github.com/paperclipai/paperclip/pull/7660))
- **Maintainer skills are better organized** - Maintainer task skills now live under `.agents`, including the create-issue-interaction UI workflow. ([#7658](https://github.com/paperclipai/paperclip/pull/7658), [#7659](https://github.com/paperclipai/paperclip/pull/7659))
- **Development tooling refreshed** - Storybook, Tailwind CSS, and Drizzle Kit development dependencies were updated, with the CN fork lockfile refreshed after merge. ([#7571](https://github.com/paperclipai/paperclip/pull/7571), [#7574](https://github.com/paperclipai/paperclip/pull/7574), [#7572](https://github.com/paperclipai/paperclip/pull/7572), [#140](https://github.com/penclipai/paperclip-cn/pull/140))

## Fixes

- **Agents no longer receive work when they are not eligible** - Invalid agents are guarded from assignments and runs. ([#7663](https://github.com/paperclipai/paperclip/pull/7663))
- **Agent CLI issue mutations are authorized with the active run** - The CLI now sends `X-Paperclip-Run-Id`, allowing agents to mutate their own issues through the intended run context. ([#7642](https://github.com/paperclipai/paperclip/pull/7642), @aronprins)
- **Git-sensitive adapter workspaces are protected** - Adapter workspace handling now avoids unsafe git-sensitive operations. ([#7644](https://github.com/paperclipai/paperclip/pull/7644))
- **Canary lockfile refresh is less noisy** - CI now guards canary lockfile commits when regeneration matches `HEAD`. ([#7692](https://github.com/paperclipai/paperclip/pull/7692))
- **CN fork sync tests are stable again** - Onboarding e2e assertions follow the current Issue launch copy, the planning visual smoke skips live adapter probes in skip-LLM mode, and heartbeat process-loss retry assertions tolerate fast lock acquisition. ([#139](https://github.com/penclipai/paperclip-cn/pull/139))

## Upgrade Guide

No manual migration is required. Existing installations can upgrade normally with `npx penclip@latest onboard` or the package manager command they already use.
